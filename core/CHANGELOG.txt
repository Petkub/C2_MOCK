POSN Practice Judge - changes

6.0  8 mock exams of 6 problems (3 hours, score /600, target 300), ordered from easy to hard, each set a little
     harder than the real exam; inside each set the problems also go from easy to hard. The problems come from a
     larger bank and cover every topic of the Camp 2 syllabus (POSN 2569); one new problem (4/1). A problem
     scores 100 only when every test passes, else 0 (like the real exam). No hints in the statements; samples
     are ordinary examples. New, cleaner statement layout; a formula never breaks across two lines.
     All sets and problems have new numbers. Folders Mock_9 ... Mock_15 of an older version are no longer used.
3.2  Stronger tests for 6/4, 6/5, 7/4, 7/5, 8/4, 10/3, 10/4 and 11/4 (some slow or wrong solutions passed too
     many). Clearer story in 8/2. The judge's help says 1.cpp ... 5.cpp.
3.1  A big test left over from an older version of a problem is rebuilt, so it is never judged with old data.
3.0  Mock sets 7 to 11 (sets 10 and 11 are harder than the real exam). Sets 5 and 6 changed: every problem
     is solved by an observation plus standard Camp 2 tools.
2.0  Mock sets 5 and 6 (harder than the real exam), and stronger big tests for sets 1 to 4.
1.9  Memory limit on macOS: a program over the limit could sometimes pass; now it always gets MLE.
1.8  Updates are much faster: files download in parallel, and a whole mock set comes as one zip.
1.7  Memory peak of a very fast program no longer shows the judge's own size (about 20 MB).
1.6  README: in VS Code open the C2_Mock_Test folder that holds Judge (an unzipped copy can be C2_Mock_Test inside C2_Mock_Test).
1.5  Memory limit (MLE) with peak memory shown; the program's stderr is shown after a crash; g++ -Wall warnings shown.
1.4  Statement PDFs, Makefile, judge.bat, README and VS Code tasks now update too (your .cpp files never).
1.3  Automatic update check every 10 minutes instead of every hour.
1.2  --update skips the GitHub cache, so a new version shows at once.
1.1  The judge updates itself from GitHub (see README.txt: --update).
1.0  First version with test data in Judge/problems/.
